### Victim (#6–#8)

```bash

# (đợi ≥ 1 phút, chuyển sang terminal KHÁC của <user_thuong>)
```

### Victim (#9–#13) — làm trong shell root

```bash

# 10: tạo (554) → sửa (550). KHÔNG daemon-reload / enable / start
printf '[Service]\nExecStart=/bin/true\n' > /etc/systemd/system/lab.service
#   (đợi 554)

# 11

#   (đợi 554)

# 12 — giả lập cập nhật binary SUID có sẵn (chỉ đổi mtime)

# 13 — dọn dẹp
```

An toàn: #9 cấp quyền cho user không tồn tại; #10 trỏ về 127.0.0.1 và không bao giờ được
nạp vào systemd; mọi file lab bị xóa ở #13. Nếu `visudo -c` báo lỗi, xóa `99-lab` từ shell root
trước khi đóng shell.
